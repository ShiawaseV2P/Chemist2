# Data credits and educational-use notes

The periodic-table view includes a compact, manually curated reference list of the 118 recognised elements: atomic number, symbol, English name, abridged atomic-mass display, group, period, broad classification, and room-temperature phase label. The dataset is intended for learning and display, not laboratory or regulatory work.

Reference sources used for cross-checking and further verification:

- IUPAC / CIAAW, [Periodic Table of Elements](https://iupac.org/what-we-do/periodic-table-of-elements/).
- Staticdata.dev, [Periodic Table dataset and methodology](https://staticdata.dev/datasets/periodic-table/), which documents the upstream `Bowserinator/Periodic-Table-JSON` project and the CIAAW standard atomic-weight basis. That published dataset identifies its data licence as **CC BY-SA 3.0** and requires attribution to the upstream project when its records are reused.
- Royal Society of Chemistry, [Periodic Table](https://www.rsc.org/periodic-table).

This app's `elements.js` values have been shortened for a compact educational display. Some superheavy-element properties are predictions, and group-3 / f-block display conventions can vary among periodic-table layouts. For precision-sensitive work, verify an element against IUPAC/CIAAW or another authoritative chemical reference.

The VSEPR, bonding, polarity, intermolecular-force and hybridisation explanations are original educational summaries written for this app. They simplify some advanced topics for an introductory high-school level; exceptions and model limitations are noted in the relevant lessons.
